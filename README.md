# 🔐 Password Strength Analyzer Pro

An advanced Cyber Security password analysis tool built with Python and Tkinter. It evaluates password strength using entropy calculation, pattern detection, character analysis, estimated crack time, and Have I Been Pwned (HIBP) breach detection through the k-Anonymity API.

## ✨ Features

- 🔒 Real-time password strength analysis
- 📊 Strength score (0–100) with visual indicator
- 🧮 Shannon entropy calculation
- ⏳ Password crack time estimation
- 🔍 Character analysis (uppercase, lowercase, digits, symbols)
- ⚠️ Detects common and weak passwords
- 🔄 Finds predictable sequences and keyboard patterns
- 📅 Detects year and phone number patterns
- 🌐 Have I Been Pwned (HIBP) breach detection
- 💡 Smart password improvement recommendations
- 👁️ Show/Hide password option
- 🎨 Modern dark-themed professional GUI
- ⚡ Fast and responsive interface

## 🛠️ Requirements

- Python 3.8+
- tkinter
- requests
