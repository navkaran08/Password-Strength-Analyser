Usage

Windows

1. Install Python 3.10+.
2. Install the required package:
   pip install requests
3. Run the application:
   python "Password Strength Analyser.py"

Linux

1. Install Python 3 and pip.
2. Install the required package:
   pip3 install requests
3. Run the application:
   python3 "Password Strength Analyser.py"

The application will launch a graphical interface where you can enter a password to analyze its strength, estimate crack time, detect common patterns, and check whether it has appeared in known data breaches.
